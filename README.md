# ULT-4-ME — Overwatch 2 Haptic Integration for Lovense & Intiface

**ULT-4-ME** is a Windows application that turns **Overwatch 2 gameplay into real-time haptic feedback** for Lovense and other Intiface-compatible devices.

It uses **real-time computer vision** to recognize **50+ gameplay detections across every Overwatch hero**, allowing connected devices to react dynamically to what is happening during a match.

> In simpler terms: it makes your Lovense go buzz when you Overwatch.

ULT-4-ME runs externally using screen capture and computer vision. It does **not** modify Overwatch 2 game files, inject code into the game, or require a game mod.

## Why ULT-4-ME?

Older Overwatch haptic integrations typically react to only a small number of global gameplay events.

ULT-4-ME goes considerably further.

* **50+ gameplay detections**
* Detection support across **every Overwatch hero**
* Hero-specific and global gameplay events
* Real-time computer vision
* Dynamic haptic intensity based on gameplay
* Broad **Lovense device support through Intiface Central**
* Configurable scoring and intensity
* External screen capture — no game-file modification
* Packaged Windows build
* No Python or Node.js installation required for the release build

Instead of simply triggering a device when you get an elimination, ULT-4-ME can respond to a much wider range of gameplay events and use those events to continuously influence haptic intensity.

## Detection System

ULT-4-ME supports **more than 50 gameplay detections across the Overwatch 2 hero roster**.

Depending on the hero and situation, detections can include things such as:

* Eliminations
* Assists
* Saves
* Deaths
* Healing-related events
* Status effects
* Hero-specific events
* Other supported gameplay indicators

The detection system is designed to react to far more than a single statistic such as the kill feed or an on-fire meter.

Because different events can contribute different amounts to the current score, device output can rise, fall, and change during gameplay.

## Features

### 🎮 Overwatch 2 Detection

Real-time computer vision monitors gameplay and recognizes supported events without modifying the game.

### 50+ Supported Detections

ULT-4-ME includes more than 50 gameplay detections spanning the Overwatch hero roster.

### Hero-Specific Detection

The system can recognize events beyond generic eliminations and assists, allowing different heroes and gameplay situations to produce different responses.

### Dynamic Haptic Feedback

Detected events contribute to a configurable score that controls device intensity.

Instead of only switching a device on or off, ULT-4-ME can produce changing output based on your performance and current gameplay events.

### Lovense Support

ULT-4-ME works with **Lovense devices through Intiface Central**.

If your supported device is connected through Intiface Central, ULT-4-ME can communicate with it through the same interface.

### Configurable Scoring

Gameplay events can contribute to a running score, with configurable scoring behavior and score decay.

### Adjustable Intensity

Control the maximum output sent to your connected device.

### Detection Overlay

An on-screen overlay can help show what ULT-4-ME is detecting while you play.

### Standalone Windows Build

The packaged Windows release does not require users to separately install Python or Node.js.

# Recommended Overwatch Settings

For best detection results, **Borderless Windowed / Borderless** display mode is recommended.

Because ULT-4-ME relies on screen capture and computer vision, changes to display resolution, interface scale, aspect ratio, or HUD configuration may affect detection.

If detections are not behaving correctly, verify your display and capture settings first.

# FAQ

## What is ULT-4-ME?

ULT-4-ME is an **Overwatch 2 haptic integration for Windows** that uses computer vision to make Lovense and other compatible devices react to gameplay events.

## Does ULT-4-ME work with Lovense?

Yes. ULT-4-ME supports **Lovense devices through Intiface Central**.

## How many Overwatch events can ULT-4-ME detect?

ULT-4-ME includes **50+ supported gameplay detections across every Overwatch hero**.

## Does it only react to eliminations?

No.

ULT-4-ME was built specifically to go beyond simple kill detection. It can recognize dozens of supported gameplay events, including global and hero-specific events.

## Does ULT-4-ME modify Overwatch?

No.

ULT-4-ME operates externally using screen capture and computer vision. It does not modify Overwatch game files or inject code into the game.

## Does it require Python?

Not when using the packaged Windows release.

Python and other development dependencies are only relevant if you are running or modifying the project from source.

## Do I need Intiface Central?

Yes.

Intiface Central provides the connection between ULT-4-ME and supported devices.

## Is ULT-4-ME only for Lovense?

No.

Lovense is one of the major supported device families, but ULT-4-ME can communicate with other compatible devices through Intiface Central as well.
